# Square Era System Database (`sesydb`)

System and session database for **Square Era** multiplayer rooms, active player sessions, and server configuration.

## Data Collections
- `data/sessions.json`: Live session registry, active connection tokens, and session expiration timestamps.
- `data/rooms.json`: 5 persistent multiplayer rooms and server configurations.
- `data/config.json`: Global game configurations, broker settings, and spawn coordinates.
- `data/backups.json`: Snapshot checkpoint logs.
